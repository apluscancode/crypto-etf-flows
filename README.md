# Bitcoin ETF Flows · ردیاب جریان ETF های بیت‌کوین

داشبورد استاتیک که نشان می‌دهد پول وارد ETF های اسپات بیت‌کوین آمریکا می‌شود یا خارج.

**زنده:** https://apluscancode.github.io/bitcoin-etf-flows/

## چطور کار می‌کند

```
GitHub Actions (هر ۳۰ دقیقه)
    └─ fetch_etf.js  →  TradingView API  →  data/etfs.json
                                              └─ commit تک‌کشویی (force-push)
                                                    └─ GitHub Pages
                                                          └─ app.js (سمت کلاینت)
```

- **بدون سرور** — نه VPS، نه cron محلی، نه دیتابیس
- **بدون کلید API** — TradingView عمومی است
- **بدون کوکی و ردیاب** — فقط یک `fetch` به `data/etfs.json`
- **بدون بیلد** — HTML + CSS + JS خالص

## متریک‌ها

| متریک | معنی |
|--------|------|
| `ratio_prem` | نسبت قیمت صندوق به BTC، امروز در مقابل میانگین ۲۰ روز. **مثبت = ورود پول** |
| `dvol` | حجم دلاری روز (close × volume) |
| `dvol_vs_avg` | حجم امروز تقسیم بر میانگین ۲۰ روزه |
| `vs_btc_20d` | بازده ۲۰ روزه صندوق منها بازده BTC — همان بازه |
| `above_ma20/50` | صندوق بالای میانگین متحرک |

### نکته‌ی مهم درباره هم‌ترازی

BTC ۲۴/۷ معامله می‌شود ولی ETF فقط دوشنبه–جمعه. اگر «۲۰ کندل BTC» را با
«۲۰ کندل ETF» مقایسه کنیم، در واقع ~۲۸ روز تقویمی را با ~۲۰ روز سنجیده‌ایم.
همه‌ی اعداد نسبی این پروژه روی **تاریخ‌های مشترک** محاسبه می‌شوند
(`aligned_days` در JSON).

## چرا پرمیوم؟

NAV لحظه‌ای ETF را بدون فید پولی نمی‌شود گرفت. ولی نسبت `ETF/BTC` یک پروکسی
تمیز است: اگر صندوق گران‌تر از معمول معامله شود، یعنی تقاضا از عرضه جلو زده
(ورود پول)؛ اگر ارزان‌تر، یعنی فروش فشار دارد (خروج پول).

بازه‌ی مرجع، میانگین همان نسبت در ۲۰ روز گذشته است — پس نوسان قیمت BTC حذف
می‌شود و فقط پرمیوم نسبی می‌ماند.

## نکات TradingView

- `timeframe` باید `'D'` باشد، نه `'1D'`
- `chart.periods` **جدیدترین اول** است — باید `reverse` شود
- IBIT فقط با `NASDAQ:IBIT` resolve می‌شود، نه `AMEX:IBIT`
- `BRRR` (Valkyrie) دیگر resolve نمی‌شود

## محدودیت‌ها

- **inflow/outflow واقعی دلاری نیست.** سایت‌های Farside و SoSoValue
  Cloudflare دارند و از runner بلاک می‌شوند. پرمیوم پروکسی است، نه عدد دقیق AUM.
- **داده با تأخیر روزانه.** ETF فقط روزهای کاری معامله می‌شود؛ آخر هفته همان
  کلوز جمعه را می‌بینی.
- **BITO و BITX** ساختار متفاوت دارند (فیوچرز و اهرمی) و در حکم کلی شمرده نمی‌شوند.

## لایسنس

کد آزاد. داده از TradingView. این ابزار آموزشی است، توصیه سرمایه‌گذاری نیست.
